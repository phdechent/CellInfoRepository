# LLM-wiki example: 2025 open-access papers

Structured, source-linked review of papers that report new measurements on
cells in this repository. Example for Section 3.3 of Dechent et al.,
*Demonstrating Linked Battery Data to Accelerate Knowledge Flow in Battery
Science* (preprint: arXiv:2410.23303).

## Contents

| Path | Content |
|---|---|
| `wiki-pages-2025-oa/` | Obsidian vault: `Index.md`, `Screening Log.md`, 33 concept pages, `papers/` (60 notes), `cells/` (34 pages) |
| `review/queue/2025-gold-diamond-used.json` | Selection and screening of all 108 candidates |
| `review/templates/cell_thermal_methods_v2.json` | Review questions Q1–Q11 |
| `agent/SKILL.md` | Agent instructions |
| `tools/` | `set_info.py`, `verify_quotes.py`, `verify_all.py`, `check_links.py` (Python 3, standard library only) |

## Method

- Agent: Claude Code with Claude Opus 5.5, 27 Sep 2026.
- Candidates: journal articles from 2025, classified `USED` for at least one
  cell, OpenAlex `oa_status` gold or diamond (108).
- Screening: skipped if the paper reports no new measurements on the target cell
  (only public or literature data, or no data): 48 skipped, 60 reviewed.
- Review: `agent/SKILL.md`, Phase 1. Answers only from explicit statements,
  each with a verbatim quotation of at most 30 words.
- Concept pages: `agent/SKILL.md`, Phase 2. Built only from the paper notes,
  every claim attributed, contradictions stated.

## Verification

Source texts are not included. Save each article's text as
`text/<doi_key>.txt` (`doi_key` as in the queue file), then run:

```bash
python tools/verify_all.py review/queue/2025-gold-diamond-used.json
python tools/check_links.py wiki-pages-2025-oa
```

## Notes

The pages are generated by an LLM agent. Quotations are verified to exist, not
their interpretation. Check against the source before use.
